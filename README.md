# Pumba (3D E-Commerce Platform)

A modern, interactive 3D e-commerce platform built with React, Three.js, and Framer Motion. This project leverages the power of React Three Fiber to seamlessly integrate 3D models and animations into a React-based UI, providing a highly immersive shopping experience.

## ✨ Features

- **3D Graphics & Animations**: Built with `three` and `@react-three/fiber` for product showcases.
- **Advanced 3D Components**: Uses `@react-three/drei` for optimized 3D rendering helpers.
- **Smooth Animations**: Incorporates `framer-motion` and `gsap` for complex, high-performance UI and 3D animations.
- **Styling**: Fully styled with Tailwind CSS (`tailwindcss`, `clsx`, `tailwind-merge`).
- **Icons**: Clean and beautiful icons provided by `lucide-react`.
- **Fast Build Tooling**: Powered by Vite and TypeScript for instantaneous HMR and strict type checking.

## 🚀 Tech Stack

- **Framework**: React 19
- **3D Library**: Three.js & React Three Fiber
- **Animations**: GSAP & Framer Motion
- **Styling**: Tailwind CSS
- **Bundler**: Vite
- **Language**: TypeScript

## 🛠️ Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ashishsharma1927-pixel/Pumba.git
   cd Pumba
   ```

2. **Install dependencies:**
   Make sure you have Node.js installed, then run:
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```
   This will start the local development server (usually at `http://localhost:5173/`).

4. **Build for production:**
   ```bash
   npm run build
   ```
   This will output the optimized static files to the `dist` directory.
